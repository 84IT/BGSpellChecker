# Български правопис — Chrome разширение

Разширение за Chrome, което:
- **Проверява правописа на български** с истински Hunspell речник (bg_BG), вграден в разширението — не разчита на Chrome да има свален български речник. Грешните думи се подчертават на всяка текстова кутия/поле (`<textarea>`, `<input>`); кликни върху подчертана дума за предложения.
- **Автоматично поправя текста**, когато напуснеш полето (или ръчно чрез бутон/десен клик):
  - `"..."` (и `…`) → `"."`
  - IP адрес, изписан със запетаи (`192,168,0,1`) → с точки (`192.168.0.1`)
  - Главна буква в началото на всяко изречение
  - Главна буква за имена от твой списък (Иван, Мария, София, ...) — списъкът се редактира от прозореца на разширението
  - Твои собствени правила за замяна (find → replace)

## Инсталация (Developer mode)

1. Разархивирай `bg-spellcheck-extension.zip`.
2. Отвори Chrome → `chrome://extensions`.
3. Включи **Developer mode** (горе вдясно).
4. Натисни **Load unpacked** и избери разархивираната папка.
5. Готово — иконата ще се появи до адресната лента.

## Употреба

- Кликни върху иконата на разширението, за да включиш/изключиш функции, да управляваш списъка с имена и собствените правила за замяна.
- Пиши във всяко текстово поле на страницата — грешно изписаните български думи ще се подчертаят с червена вълниста линия; кликни върху тях за предложения.
- Когато излезеш от полето (blur), автоматичните поправки (точки, IP, главни букви) се прилагат сами, ако е включено.
- Три начина да задействаш поправка ръчно по всяко време:
  - Бутонът **"Поправи текущото поле"** в прозореца на разширението
  - Десен клик в полето → **"Поправи текста"**
  - Клавишна комбинация **Ctrl+Shift+Y** (Cmd+Shift+Y на Mac) — работи дори в popup прозорци без видима лента с икони

## Отстраняване на проблеми

- **Иконата на разширението показва червено "!"** за няколко секунди → съобщението не е достигнало до страницата. Презареди страницата (F5) и опитай пак — разширението не се инжектира автоматично в раздели, които са били отворени преди инсталиране/презареждане на разширението.
- **Manifest грешки при зареждане** → увери се, че папката, която избираш в "Load unpacked", съдържа `manifest.json` директно (не в подпапка).
- За диагностика: отвори DevTools (F12) на страницата, където тестваш → Console → трябва да видиш `[BG Spellcheck] content script loaded on ...`. Ако го няма, скриптът не е инжектиран в тази страница/прозорец.
- chrome:// страници, Chrome Web Store и `file://` адреси (без изрично разрешение) не поддържат разширения — това е ограничение на Chrome, не бъг.

## Технически бележки

- Речникът е официалният отворен `dictionary-bg` (Hunspell bg_BG), зареждан през `nspell` — работи изцяло локално в браузъра, без изпращане на текст към сървър.
- Подчертаването за `<textarea>`/`<input>` използва техника с прозрачно поле върху огледален слой (overlay), затова точното визуално подравняване може леко да варира при силно нестандартни стилове на конкретни сайтове.
- За `contenteditable` полета (напр. Gmail, богати текстови редактори) разширението активира вградената проверка на Chrome (`spellcheck`/`lang="bg"`) и прилага само текстовите поправки на обикновен текст, за да не поврежда форматирането (получер шрифт, връзки и т.н.).
- Никакви данни не се изпращат извън браузъра — всичко (речник + правила) работи локално.

## Файлова структура

```
manifest.json       — конфигурация на разширението (Manifest V3)
background.js        — контекстно меню ("Поправи текста")
content.bundle.js     — основна логика (bundled: правила + nspell speller + overlay)
content.css           — стилове за подчертаване и меню с предложения
popup.html/js/css     — прозорец за настройки
dict/bg.aff, bg.dic    — Hunspell речник (bg_BG)
icons/                — икони на разширението
```
